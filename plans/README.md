# Animation improvement plans

Generated by `/improve-animations` from the `/review-animations` and `/find-animation-opportunities` passes run earlier in this session (commit `bf245a3`). All 15 candidates were approved for planning ("all of them"). All 17 plans (001-017) have since been implemented and deployed.

**Post-implementation note (016/017):** after landing, the entrance values in 016 and 017 (24-32px travel, flat `ease-out`, opacity/y only) read as too subtle in practice. A follow-up pass increased travel distance (48-72px), added a scale pop (0.82-0.92 -> 1) to every entrance, and switched most curves from flat `ease-out` to spring physics (`stiffness 140-200, damping 16-18`). The plan files below still show the original, more conservative values — treat the live code as current, not these two files' literal numbers.

Two plans (010, 011, 012) bake in a default decision on a product/behavior question that was left open in the audit — each states its assumption explicitly at the top ("Decision this plan bakes in"). If you disagree with the assumption, don't execute that plan; say what you'd rather do instead and a replacement plan can be written.
